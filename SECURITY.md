# Security

## Which versions get fixes

Only the newest release. StationPlay is still in alpha, so a fix comes as a new release, not as a change to an older one. Keep StationPlay up to date (README: [Updating](README.md#updating)).

## Reporting a problem

Please report a security problem privately, never in a public issue:

1. Open StationPlay's page on GitHub: <https://github.com/egadgetboy/stationplay>.
2. Choose the **Security** tab, then **Report a vulnerability**.
3. Say what you found, which version, and the steps that show it.

Only StationPlay's maintainer sees the report.

## What happens next

- You'll get a reply within 7 days.
- Once the problem is confirmed, the fix comes in the next release, as soon as it's ready and tested. Its release notes say what was fixed.
- You'll be credited in the notes if you'd like to be.

Please give the fix time to ship before you tell anyone else about the problem.

## What's in scope

StationPlay itself: the server, its page and its API. Problems in Plex, Jellyfin, FFmpeg or Debian belong with those projects.
