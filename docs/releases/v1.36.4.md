A hotfix: INFO plays again, and Night mode cuts deep rumble.

## Fixed

- **INFO said "We'll be right back."** Since 1.35.0, tapiOca looked for INFO's film among your own files, because the code it goes by looks like a Media folder's. It was never there, so station 99 showed its card instead. tapiOca now finds the film where it keeps it.
- **Night mode let deep rumble through.** It now cuts sound under 50 Hz, steeply, so explosions don't shake the room or pull the voices down. Bass from 100 Hz up is as it was. This is the sound tapiOca makes for Apple's and Roku's apps, and for Media copies made with Night mode. tapiOca for Android 0.6.3 makes it the same way on the device.

## Updating

`tapioca-1.36.4.zip` is the source. Update as the banner, or [Updating](https://github.com/egadgetboy/tapioca-server#updating), says. Nothing in the database changes.

## Rolling back

Use the image `ghcr.io/egadgetboy/tapioca-server:1.36.3` (see [Rolling back](https://github.com/egadgetboy/tapioca-server#rolling-back)). 1.36.3 runs on 1.36.4's database as it is. INFO then shows its card again, and Night mode lets rumble through.
