This release plays files a player can't decode, keeps file names out of the apps, explains problems from the apps better and backs up the database before an update changes it.

## New

- **A database copy before updates.** Before an update changes StationPlay's database, it copies it, sign-ins included, to `data/backups` as `before-<version>-<date>.db` and keeps the newest 3 copies.
- **Safe if it can't copy.** If the copy fails (because the disk is full, for example), the update changes nothing, logs why and stops.

## Fixed

- **Files a player can't decode.** When a player can't decode a file, as on some Samsung phones, the apps can now ask for a converted copy instead of trying again. It plays from the same point, with the same version, sound, subtitles and night mode, within the quality you allow away from home.
- **What the copy is.** It's H.264 at up to 1080p, with AAC sound in 5.1 where the device takes surround sound, and it counts toward the copies converted at once.
- **Wide films and the limit.** A wide film converted at 1080p is now 1920 pixels wide, as 1080p players expect. Devices asking at the same moment can no longer all get past the limit on converted copies.
- **No file names in apps.** Nothing the apps receive names a file or folder. The page and the log still name files, for Admins.
- **More to go on.** On the **Logs** tab, each known problem now shows **What it means** in plain words, then **What the app said** and **What led up to it**.
- **Lost connections reported.** An app that can't reach StationPlay for a minute or more reports it once it's back ("Den couldn't reach StationPlay for 12 minutes · No network on this device").

## Good to know

- **Subtitles, not captions.** What StationPlay sends the apps, and its documents, now say subtitles instead of captions.
- **Updated apps.** Asking for a converted copy, the lines leading up to each problem and reporting lost connections come with the apps' own updates (StationPlay for Android 0.3.1).

## Updating

**Files.** `stationplay-1.29.1.zip` is the app (it unzips to `src`). `stationplay.yaml` is the app definition for TrueNAS SCALE, and `docker-compose.yml` is for everything else.

First unzip `stationplay-1.29.1.zip` over `src`. Then change only the version in `image:` to `stationplay:1.29.1` (see [Updating](https://github.com/egadgetboy/stationplay#updating)). Your stations, settings and sign-ins are kept, and so is your Plex token. As it starts, 1.29.1 saves a copy of the database in `data/backups` as `before-1.29.1-<date>.db`, then updates it. For a new install, see [Install](https://github.com/egadgetboy/stationplay#install).

## Rolling back

To go back to 1.29.0 (see [Rolling back](https://github.com/egadgetboy/stationplay#rolling-back)):

1. Stop StationPlay.
2. In the data folder, replace `stationplay.db` with `backups/before-1.29.1-<date>.db`, and delete `stationplay.db-wal` and `stationplay.db-shm` if they're there.
3. Unzip `stationplay-1.29.0.zip` over `src`.
4. Change `image:` back to `stationplay:1.29.0`, and start it.

Everyone stays signed in, and everything is as it was just before the update. Anything changed since is lost.
