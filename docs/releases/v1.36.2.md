This release makes the page easier to read, lists INFO in 4-hour blocks in the guide, keeps changes to tapiOca on its own page, and keeps Plex's tuner working beside a trusted proxy.

## New

- **Easier to read.** The page's text now uses your device's own font (San Francisco, Segoe UI or Roboto), a little larger. Headings are sized above the text they head. tapiOca's own font stays on headings, tabs and buttons.
- **INFO in the guide.** INFO now shows as back-to-back 4-hour listings from midnight, each saying what it shows, in Plex's guide and every other. Before, Plex listed it every 2 minutes, with "Unknown" before the first.

## Fixed

- **Changes from another site's page.** At home over plain http, browsers don't say which site sent a request. So with sign-in off, or an Admin signed in, another site's page could make changes. Now every change needs a header that only tapiOca's own page sends. Scripts and apps aren't affected.
- **Plex beside a trusted proxy.** Plex, or anything else on the trusted proxy's computer, could lose the tuner and guide. A trusted proxy that names no visitor is now taken as its own computer, at home, and nothing from it skips signing in. **Trust this proxy** is offered for Plex's address too.
- **Away from home with sign-in off.** The check showed this as a problem ("Down"). Now it says your address works, and that turning on sign-in is the step left. In setup, a button takes you there.
- **What apps say.** An app turned away from outside now tells the person watching "This address can't be used from outside your home." The Admin finds why in the log. A few other messages are reworded the same way.
- **INFO on Broken files.** INFO's film could be checked and listed as broken, taking INFO off the air. It's never checked now, and a listing from before comes off.
- **Trusted proxies,** in plain words. A proxy you just trusted no longer shows as "isn't a trusted proxy."

## Updating

`tapioca-1.36.2.zip` is the source. Update as the banner, or [Updating](https://github.com/egadgetboy/tapioca-server#updating), says. Nothing in the database changes, so no copy is made. A web page of your own that changes things through tapiOca's API needs a token, or the header `X-Tapioca-Page: 1`.

## Rolling back

To go back to 1.36.1, use the image `ghcr.io/egadgetboy/tapioca-server:1.36.1` (see [Rolling back](https://github.com/egadgetboy/tapioca-server#rolling-back)). Nothing needs putting back. If Plex shares an address with a proxy you trusted, 1.36.1 takes the tuner from Plex, so remove that proxy first.
