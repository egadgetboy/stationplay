**A safeguard for passcodes.**

- **No one locks someone else out.** On Who's tuning in?, anyone at a device can pick someone who has no passcode, so that sign-in no longer sets a passcode for them, or chooses none. To set one, they sign in on the device with their password or an invite code first (in the apps, **Someone else is watching** in Options, then signing in by name). A sign-in made with a password, an invite code or a passcode works as before, and so does setting or removing anyone's PIN on the **Access** tab.

**Files.** `stationplay-1.28.1.zip` is the app (it unzips to `src`); `stationplay.yaml` is the app definition for TrueNAS SCALE, and `docker-compose.yml` for everything else.

**Updating.** Unzip `stationplay-1.28.1.zip` over `src` first, then change only the version in `image:` to `stationplay:1.28.1` (see [Updating](https://github.com/egadgetboy/stationplay#updating)). Your stations and settings are kept. **New install:** see [Install](https://github.com/egadgetboy/stationplay#install).
