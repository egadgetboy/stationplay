StationPlay now has a documented API with tokens, versions of a title, and Skip intro and Skip credits.

## New

- **StationPlay's API.** `/api/v1` is now a documented, versioned API for your scripts, home automation and players, with an OpenAPI spec at `/api/v1/openapi.json`. See [docs/api.md](https://github.com/egadgetboy/stationplay/blob/v1.22.0/docs/api.md).
- **What the API covers.** It covers the server, stations, guide, streams and status. Admins can also update a station from Plex, check a station's files, ask Plex to refresh its guide and make a backup.
- **API tokens.** Make Viewer (read only) or Admin tokens on the **Access** tab, with or without an expiry. Each is shown once, stored only as a hash and can be revoked at any time.
- **Versions of a title.** A title in 4K and 1080p is listed once. Each device plays the version chosen, or the best one it can play without converting and its connection can handle.
- **A smaller version when needed.** When playback can't keep up, the app offers a smaller version from where you are, or switches on its own, as an Admin chooses for home and away.
- **Skip intro and Skip credits.** Episodes offer them where Plex's markers fit the file. Movies don't.

## Good to know

- **A stable version 1.** A change that would break a client becomes version 2. The old address then sends `Deprecation` and `Sunset` headers for at least 6 months.
- **Tokens and the internet.** Tokens work only with the API, and from the internet only if an Admin allows it, over HTTPS.
- **App-only calls moved.** Calls used only by StationPlay's apps, such as signing in, moved from `/api/v1` to `/api/internal`, which isn't public. The apps need 1.22.0 or newer.

## Updating

**Files.** `stationplay-1.22.0.zip` is the app (it unzips to `src`). `stationplay.yaml` is the app definition for TrueNAS SCALE, and `docker-compose.yml` is for everything else.

First unzip `stationplay-1.22.0.zip` over `src`. Then change only the version in `image:` to `stationplay:1.22.0` (see [Updating](https://github.com/egadgetboy/stationplay#updating)). Your stations and settings are kept. For a new install, see [Install](https://github.com/egadgetboy/stationplay#install).
